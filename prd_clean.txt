Field Detail Author Reshant Dewangan Document Owner Reshant Dewangan (Product / Design / Content) Date July 25, 2026 Version 1.0 — Draft Status For Review Design Reference &quot;Subtle Folio&quot; — Framer portfolio template (screenshots provided) 1. Overview &amp; Purpose Reshant Dewangan is a Data Analyst skilled in SQL, Python, Power BI, Tableau, and Advanced Excel, currently building a personal portfolio website to showcase his analytics projects, professional experience, and certifications. The site&apos;s goal is to convert visitors — recruiters, hiring managers, and potential clients — into interview requests or freelance/collaboration inquiries. This PRD defines the site&apos;s structure, content, visual design system, and functional requirements. The visual direction is adapted from an inspiration portfolio template (screenshots provided): a clean, card-based, light-mode layout with a persistent icon navigation bar, an &quot;Available for Work&quot; status badge, and a black primary call-to-action button. The same structure is repurposed here for a data-analyst context — replacing &quot;Projects&quot; (design case studies) with data analytics case studies, dashboards, and SQL/Python deep-dives. 1.1 Problem Statement Reshant&apos;s resume is dense with 10+ quantified analytics projects, but a resume/PDF cannot show interactive dashboards, SQL logic, or visual storytelling. Recruiters spend seconds scanning a candidate; there is no single, visual, credibility-building link to share in applications or on LinkedIn. A portfolio site solves this by presenting the same experience as scannable, visual case studies with proof (screenshots, KPIs, links to GitHub/Power BI/Tableau). 1.2 Goals &amp; Success Metrics Goal Success Metric Get more interview / recruiter callbacks ≥ 5% of visitors click &quot;Hire Me&quot; / submit an inquiry Clearly communicate technical breadth Visitor can identify 3+ tools (SQL, Power BI, Python) within 10 seconds on Home Showcase depth of project work Avg. time on Projects page &gt; 60 seconds; ≥ 3 case studies opened per session Make resume/contact easy to obtain Resume download and &quot;Copy Email&quot; used by ≥ 15% of visitors Be usable on mobile (shared via LinkedIn/WhatsApp) Mobile bounce rate &lt; 40% 1.3 Target Audience Primary: Technical recruiters and hiring managers at analytics/BI/data teams evaluating an entry-level Data Analyst. Secondary: Startup founders / small businesses looking to hire a freelance analyst for dashboarding or reporting work. Tertiary: Peers, mentors, and LinkedIn network reviewing work for referrals or collaboration. 2. Design Direction Visual language is adapted from the provided &quot;Subtle Folio&quot;-style reference: soft light-gray canvas, white rounded cards with subtle shadows, a compact top icon-navigation bar, pill-shaped status badge, and a solid black primary button. Warmth and personality come from a rounded avatar/illustration and colored project icons; everything else stays neutral and text-forward so the analytics content (numbers, charts) stays the focus. 2.1 Color Palette Swatch Hex Token Usage #F1F1F3 Canvas / Page BG Overall page background #FFFFFF Surface / Card Nav bar, content cards, sections #1C1C22 Ink / Primary Text Headings, body copy #6B7280 Muted / Secondary Text Descriptions, metadata, captions #111114 Accent Black (CTA) &quot;Hire Me&quot; button, primary buttons, footer bar #15803D Success Green &quot;Available for Work&quot; badge text #DCFCE7 Success Green BG &quot;Available for Work&quot; badge background #6C4CE0 Brand Accent (optional) Rectangle-style project icon / link highlight / hover state #E3E3E7 Border / Divider Card borders, input borders, dividers 2.2 Typography Role Typeface Weight / Size (web px) Notes Display / Hero (&quot;I&apos;m Reshant Dewangan&quot;) Poppins / General Sans SemiBold–Bold, 40–48px Rounded geometric sans matching reference screenshots Section Headings Poppins SemiBold, 22–28px Small uppercase eyebrow label above each heading, e.g. • Projects Body Text Inter Regular, 15–16px High legibility for descriptions &amp; bullet points Buttons / Labels / Badges Inter Medium, 13–14px All-caps optional for badges only Metadata (dates, tags) Inter Regular, 13px, muted gray Used in project cards and case-study meta rows 2.3 Core UI Components (from reference) Sticky top nav: logo/home icon + 4 icon links (Home, About, Projects, Contact) + solid black &quot;Hire Me&quot; pill button, right-aligned. Status badge: pill-shaped, light green background, dark green text, small dot — &quot;Available for Work.&quot; Hero card: greeting headline, 2-line role/location summary, avatar or illustrated portrait, two buttons (&quot;Hire Me&quot; filled black, &quot;Copy Email&quot; / &quot;Download Resume&quot; outlined). Project / case-study cards: colored rounded icon (initial or logo), title, one-line tag of skills used, chevron affordance, on white rounded card with soft shadow. Case-study detail page: meta table (Client/Role, Tools, Type, Year), title, summary paragraph, &quot;Visit Website&quot;/&quot;View Dashboard&quot; button, hero screenshot, then narrative sections (Problem, Approach, Key Insights, Impact). Contact / &quot;Hire Me&quot; section: headline, subcopy, Name/Email inputs, Message textarea, full-width black submit button, social icon row, footer credit line. All cards use consistent 16–20px corner radius, 24px internal padding, and a light 1px border or soft drop shadow instead of hard outlines. 3. Functional Requirements ID Requirement Priority FR-1 Sticky top navigation with icon links (Home, About, Projects, Contact) and a persistent &quot;Hire Me&quot; button Must FR-2 &quot;Available for Work&quot; status badge, manually toggleable by the site owner (config flag) Must FR-3 &quot;Copy Email&quot; button copies email to clipboard with confirmation toast Must FR-4 Downloadable resume PDF, linked from Home, About, and Contact Must FR-5 Projects grid with individual case-study detail pages, each with unique URL slug Must FR-6 Filter/tag projects by tool (SQL, Python, Power BI, Excel) Should FR-7 Contact form submits Name/Email/Message via email service (e.g. Formspree/EmailJS) or mailto fallback Must FR-8 Social links open in new tab: LinkedIn, GitHub, LeetCode, HackerRank Must FR-9 Smooth scroll / anchor navigation between Home sections Should FR-10 Previous/Next project navigation on case study detail pages Could FR-11 Basic analytics (page views, CTA clicks) via privacy-friendly analytics tool Should 6. Non-Functional Requirements Responsive: fully usable at mobile (360px), tablet (768px), and desktop (1280px+) widths, matching the reference&apos;s single-column card stacking on narrow viewports. Performance: Lighthouse performance score ≥ 90; hero content visible within 2 seconds on 4G. Accessibility: WCAG 2.1 AA — sufficient color contrast for gray text on white/gray backgrounds, alt text on all icons/images, keyboard-navigable nav and form. SEO: descriptive page titles/meta tags, Open Graph image for link previews (LinkedIn/WhatsApp shares), semantic HTML headings. Cross-browser support: latest Chrome, Safari, Edge, Firefox. Maintainability: project/case-study content structured as data (JSON/CMS) so new projects can be added without code changes. 7. Suggested Tech Stack Not prescriptive — any stack that satisfies the functional/non-functional requirements is acceptable. A lightweight option: Framework: Next.js / React (or a no-code builder such as Framer, matching the reference template&apos;s origin) Styling: Tailwind CSS for the card/pill/badge system described in Section 2 Form handling: Formspree, EmailJS, or a simple serverless function Hosting: Vercel / Netlify Content: project data stored as structured JSON/Markdown so the 10 case studies can be templated 8.
